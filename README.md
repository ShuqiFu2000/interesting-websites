# Interesting Websites

A personal collection of interesting, useful, and beautifully made corners of the web.

## History 

### [江山时序 · 中国历史地图时间轴](https://deanchen.me/jiangshan-map/)

从战国到现代的交互式中国历史地图，可浏览历代疆域、州郡政区、古今地名、重大事件与人物行迹。

**Tags:** `history` · `map` · `interactive` · `China`

### [红军长征历史历程演示](https://myehtwh911in.meoo.zone/)

通过二维地图展示 55 个长征节点，以动态路线串联瑞金、湘江战役、遵义会议、四渡赤水、飞夺泸定桥、吴起镇与会宁会师等重要地点和事件。

**Tags:** `history` · `map` · `interactive` · `Long March`


## Space 

### [NASA Eyes](https://science.nasa.gov/eyes/)

NASA 的浏览器端 3D 可视化应用合集，利用真实任务数据和图像探索太阳系、小行星、地球、系外行星与深空通信。

**Tags:** `NASA` · `space` · `3D` · `data visualization` · `interactive`
